# Lab 4 – JavaScript Quiz Game (Console Based)

## Lab Title
JavaScript Quiz Game using arrays, loops, functions, conditionals, and browser console input/output.

## Description
This assignment involves building a simple quiz game in JavaScript that runs entirely inside the browser console. The quiz uses an array of question objects, loops through them using a for loop, takes user input through prompt(), validates the input using toLowerCase() and trim(), and gives immediate feedback through alert(). A score counter keeps track of correct answers, and the final score is shown at the end.

## Learning Outcomes
- Use arrays to store structured quiz data  
- Implement loops and conditionals  
- Create reusable functions  
- Take input using prompt() and display output using alert()  
- Validate user input with string methods  
- Track and update quiz score  
- Run JavaScript programs in the browser console

## Project Structure
quiz/  
 ├── quiz.js – Contains all quiz logic (questions array, loop, score system, feedback)  
 └── README.md – Description, instructions, learning outcomes, and usage steps

## How the Quiz Works
1. A quizQuestions array stores all questions and answers  
2. The runQuiz() function executes the quiz  
3. Each question appears using prompt()  
4. User input is cleaned with toLowerCase() and trim()  
5. Correct answers increase the score  
6. Alerts provide immediate feedback  
7. Final score is displayed after all questions

## How to Run the Quiz
1. Open any browser  
2. Press F12 and go to the Console tab  
3. Copy/paste the entire quiz.js code  
4. Press Enter to start the quiz  
5. Answer each question and view the total score at the end
