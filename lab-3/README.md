---

## 📌 **Description**
This lab focuses on creating a fully responsive one-page personal portfolio website using only **HTML5 and CSS3**.  
The goal is to demonstrate understanding of modern CSS layout systems such as **Flexbox** and **CSS Grid**, along with responsive design principles, animations, transitions, and semantic HTML structuring.

The website includes the following sections:
- Header with navigation  
- Hero section with image and introduction  
- About section  
- Skills section (Grid based)  
- Projects section (Grid based)  
- Contact form  
- Footer  

All layouts are responsive and adapt smoothly to different screen sizes.

---

## 🧩 **Key Features Implemented**
- Flexbox used for header, hero layout, and footer  
- CSS Grid used for skills and project cards  
- Responsive design using media queries (mobile, tablet, desktop)  
- Relative units used: `rem`, `em`, `%`, `vw`, `vh`  
- Smooth hover effects on buttons, links, and cards  
- Keyframe animation added to highlight text  
- Clean and semantic HTML structure  
- Simple, modern, user-friendly design  

---

## 📱 **Responsive Behavior (Breakpoints Tested)**

### **1. Mobile (≤ 480px – 600px)**
- Navigation collapses automatically  
- Hero section stacks vertically  
- Image resizes proportionally  
- Grid sections become single-column  

### **2. Tablet (~768px)**
- Grid adapts to 2-column layout  
- Hero image reduces size  
- Better spacing and alignment  

### **3. Desktop (≥ 1024px)**
- Full multi-column layout  
- Hero uses side-by-side Flexbox  
- Skills & projects show 3-column or auto-fit grid  

Responsive behavior ensures the layout is readable and clean across all screen sizes.
